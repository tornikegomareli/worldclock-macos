# Privacy

WorldClock has no accounts, advertising, or analytics.

Saved cities and preferences stay on your Mac. City search, time conversion, daylight calculations, and globe imagery work offline.

If you enable automatic Home location, macOS asks for location permission. WorldClock matches your location to the nearest city locally. If weather is enabled in a WeatherKit-capable build, it sends the city's coordinates to Apple Weather. Weather requests do not use a WorldClock server.

Signed releases can check GitHub for updates through Sparkle. Automatic checks are off until you enable them. GitHub receives normal connection information, including your IP address; Sparkle can send the installed app and macOS versions. System profiling is disabled. Update archives use cryptographic signatures.

Update notifications are optional and use macOS Notification Center. They do not use remote push notifications. Disabling them does not disable the update reminder inside the app.
